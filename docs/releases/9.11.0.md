## Clio 9.11.0

Update for Clio (formerly Futon MihonFix). Same package IDs and certificate as 9.10.0, so it updates in place and keeps
your data: **Futon-MihonFix-9.11.0.apk** (standalone, `io.github.madebycli.futon.mihonfix`) or
**Futon-9.11.0-legacy-update.apk** (legacy update of an existing installation, `io.github.landwarderer.futon`).

### What is new
- **Sources:** disabled sources stay disabled after restart, rescan and extension updates. Source management shows
  loading, empty and error states with a retry. Source lists say "Built-in" or "Mihon extension".
- **Chapters:** group headings in the theme accent, no empty headings, complementary Mihon groups stay selectable, the
  Pages/Chapters/Bookmarks tabs stay visible, German texts for the merge switch.
- **Extensions:** update check at startup with an optional notification. Nothing is installed without you.
- **Clio:** Clio mark on the welcome screen and the splash; About reads "formerly Futon MihonFix".

### Validation
Publication requires the project's release gates: focused Mihon, reader, chapter, source and onboarding tests, a debug
build, two optimized R8 builds, package, version, ABI and certificate verification and Android 16 emulator installation
checks. The changes in this release have **not** been verified on a physical device. Full project lint remains
diagnostic (known legacy findings).
