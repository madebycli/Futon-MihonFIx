## Clio 10.2

A fix release for extensions.

### Fixed

- **No more crash when an extension stops its work.** Newer extensions are built with a newer version of a shared
  library than Clio shipped. When such an extension stopped work in the background, for example because you opened
  a manga while the check for new chapters was running, the app could crash. Clio now ships a version that works with
  both older and newer extensions, and every release is checked for it.

Everything from 10.0 and 10.1 is included.
