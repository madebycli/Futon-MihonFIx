## Clio 9.11.1

Fix release for Clio 9.11.0. Same package IDs and certificate, so it updates in place and keeps your data:
**Futon-MihonFix-9.11.1.apk** (standalone, `io.github.madebycli.futon.mihonfix`) or
**Futon-9.11.1-legacy-update.apk** (legacy update of an existing installation, `io.github.landwarderer.futon`).

### What is new
- **Extensions:** no more "not supported" in the settings of a source after a restart, real extension icons instead of
  white squares, source names on filter chips.
- **Chapters:** Comix and other WebView-based extensions load more reliably. The first load of a long list still takes up
  to a minute, because the extension reads it page by page.
- **Explore:** the sources are a list by default, with an update button on rows whose extension has an update.

### Validation
Publication requires the project's release gates: focused Mihon, reader, chapter, source and onboarding tests, a debug
build, two optimized R8 builds, package, version, ABI and certificate verification and Android 16 emulator installation
checks. The chapter loading of Comix was confirmed on a device (474 of 474 chapters); the update button has not been tried
against a real extension update. Full project lint remains diagnostic (known legacy findings).
