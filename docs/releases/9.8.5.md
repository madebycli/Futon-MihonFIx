## Futon 9.8.5

### AppFuton upstream sync

This release integrates all six missing commits from AppFuton/Futon through
5d2206a6926adf53be0867ad784948ed16663f44, including the upstream 9.8.2 changes:

- Protect newer saved reading progress from stale metadata recalculation.
- Optional smart resume for newly available chapters, disabled by default and configurable in Reader settings.
- Fix next-chapter prefetch and preserve readable pages when a successor fails or is empty.
- Update built-in parsers to b3c0000245, including source fixes from the upstream parser release.
- Update Android SDK setup actions to v4.

### Downstream compatibility

The upstream commits do not replace our Mihon/Keiyoushi host fixes. Modern source ABI,
interceptor ordering, classloader ownership, durable metadata snapshots and external Comix grouping
remain in place. Smart resume uses Comix's complete chapter list when numbers are unique.
Duplicate/uncertain Comix chapters still retain group views; no extension fork is introduced.

### Upgrade and validation

Version 9.8.5 / versionCode 90805, same application ID and release signing certificate as 9.8.4.
Release publication is gated by reader, Mihon and Comix regressions, optimized R8 build,
host ABI inspection, APK version and certificate verification. Legacy release lint stays diagnostic.
Real-device and instrumented runtime retests remain PENDING unless separate evidence is recorded.
