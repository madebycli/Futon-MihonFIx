## Clio 9.10.0

Futon MihonFix is now **Clio**. It is the same app with the same package IDs and certificate, so it updates in place
and keeps your data: use **Futon-MihonFix-9.10.0.apk** (standalone, `io.github.madebycli.futon.mihonfix`) or
**Futon-9.10.0-legacy-update.apk** (legacy update of an existing installation, `io.github.landwarderer.futon`).
Both are signed with the existing repository release key.

### What is new
- **Chapters:** all chapter groups of a manga in one list, headers only where the volume or group changes, repeated
  chapters shown once. Switch: chapters menu and Settings > Appearance > Details ("Merge chapter groups", on by default).
- **Descriptions:** Markdown from extension descriptions is formatted (bold, italic, lists, quotes, links); only http(s)
  links are clickable. No more jumping when expanding or collapsing a description.
- **Mihon extensions:** current Kototoro Cloudflare handling and extension runtime, safer logs, correct pages for chapters
  that repeat the first image.
- **Upstream (AppFuton 127c51d):** double-page reader rework, JPEG XL, E-Ink flash, source presets, pinned favourites and
  library filters, source replacement with alternatives, tracker and download fixes, custom themes.

### Before you update
- The database is migrated to version 31. Export a backup first; going back to 9.9.0 afterwards is not possible without
  losing data.
- New backups are named `clio_<date>.bk.zip`; older `futon_*` backups still restore.
- No donation link exists in this project or in the Futon upstream, so there is none in the app.

### Validation
Publication requires the project's release gates: focused Mihon, reader and chapter tests, a debug build, two optimized
R8 builds, package, version, ABI and certificate verification and Android 16 emulator installation checks. The new
chapter list, description fix and Cloudflare handling have **not** been verified on a physical device, and the translations
of the new name were replaced mechanically. Full project lint remains diagnostic (known legacy findings).
