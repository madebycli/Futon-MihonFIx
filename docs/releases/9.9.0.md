## Futon MihonFix 9.9.0

### Installation conflict fix
Use **Futon-MihonFix-9.9.0.apk** for a separate installation on Samsung Galaxy devices and other Android phones.
It uses `io.github.madebycli.futon.mihonfix`, separate content providers and a separate sync account type.
It can coexist with original Futon or an older development build and uses the existing repository release key.

Existing installations signed by this repository can instead update in place with **Futon-9.9.0-legacy-update.apk**.
The legacy package and certificate remain unchanged. A differently signed original Futon cannot be updated by this APK.
The separate app has its own data; export a backup from the existing app and restore it in MihonFix if needed.

The reported `failureConflict` and successful development build indicate a package/signature conflict; the exact
device-side PackageManager reason was not supplied. This release fixes the shared identity path without deleting data.
